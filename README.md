# Mi Salud - Gestión de Signos Vitales en Java ☕

¡Bienvenido a **Mi Salud**! Este es un programa de consola desarrollado en Java utilizando los fundamentos de la **Programación Orientada a Objetos (POO)**. El sistema permite registrar los datos de un paciente y realizar un seguimiento y diagnóstico clínico básico de sus signos vitales.

## 🚀 Características
* **Encapsulamiento estricto:** Atributos protegidos con accesos validados mediante Getters y Setters (los nombres de los pacientes se estandarizan automáticamente a mayúsculas).
* **Cálculo dinámico:** La edad del paciente se calcula de forma lógica basándose en su año de nacimiento.
* **Módulos de Diagnóstico Clínico:** Evaluaciones automáticas siguiendo parámetros médicos estándar para:
  * Presión Arterial (Hipertensión / Hipotensión)
  * Glucemia Capilar (Rangos ADA para control en ayunas)
  * Frecuencia Cardíaca (Taquicardia / Bradicardia)
  * Frecuencia Respiratoria
* **Interfaz Interactiva:** Menú de consola guiado por un bucle `do-while` y estructura `switch` para una navegación fluida.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** Java 
* **Herramientas:** Eclipse / Visual Studio Code
* **Entrada de datos:** Clase `Scanner` de Java
